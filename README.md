# 苗银錾刻工坊

浏览器里的苗银錾刻浮雕设计与预览系统。TypeScript + WebGPU, 所有设计稿保存在本机浏览器 (IndexedDB), 不上传任何数据。

## 运行

```bash
pnpm install
pnpm dev
```

构建: `pnpm build`

## 页面

- **作品列表** — 银冠 / 项圈 / 手镯 / 银片分类管理, 底坯形状厚度尺寸可设, 作品可复制成新款
- **纹样稿** — 手绘、导入线稿图 (可自动描线)、内置花鸟鱼蝶龙云纹样
- **錾刻编辑** — 圆头 / 平头 / 线錾 / 珠錾, 每锤有位置方向力度, 单锤、沿线批量、沿纹样排锤
- **银面预览** — WebGPU 金属渲染, 錾痕反光, 做旧发黑 (凹暗凸亮), 弯曲成镯/冠后浮雕拉伸效果
- **工艺回放** — 逐锤回放, 进度条拖动, 任意一锤前后对比
- **工单** — 用银重量、錾子清单、锤数、预计工时, 可打印

## 核心模型

- 银片是高度场 + 厚度场。每一锤是一个局部位移核 (錾子截面轮廓), 背面锤向外推凸, 正面锤压入细节
- **确定性**: 变形是纯定点顺序浮点运算, 同一锤点序列敲两遍结果逐比特一致; 回放即按序列重放
- **体积守恒**: 每锤排开的体积等额摊到周围厚度变化上, 状态栏实时显示守恒误差; 敲穿钳制是唯一破例, 会明确计数提示
- **变薄提示**: 局部剩余厚度低于 35% 警告, 低于 20% 强警告, 敲穿计数
- 性能: 每锤只触及核内几百个网格点, 两千锤全量重算毫秒级, 编辑实时

## 导出

- 高度图 PNG (灰度归一化) 与 OBJ 网格 (含弯曲、含法线), 可直接给 3D 打印做蜡模
